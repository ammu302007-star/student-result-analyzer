# Student Result Analyzer

C project for managing student marks and generating simple result statistics.

## Features

- Add student records
- Display student results
- Calculate total marks
- Calculate average marks
- Find the topper
- Find the lowest scorer
- Search for a student by roll number
- Sort students by total marks
- Show class statistics
- Calculate pass/fail status
- Assign grades

## Concepts Used

- Variables and data types
- If-else statements
- Loops
- 1D arrays
- 2D arrays
- Strings
- Functions
- Function parameters
- Return values
- Linear search
- Sorting
